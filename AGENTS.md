# AGENTS.md

Este proyecto se está configurando desde cero.

## Reglas generales para Codex

- Antes de modificar archivos, explicar brevemente el plan.
- No borrar archivos sin confirmación explícita.
- Hacer cambios pequeños, claros y localizados.
- No reformatear todo el proyecto salvo que se pida explícitamente.
- Si se agrega lógica nueva, proponer también cómo probarla.
- Si hay dudas sobre el objetivo, preguntar antes de avanzar.
- Mantener el código simple y legible.
- Evitar dependencias innecesarias.

## Flujo de trabajo esperado

Antes de editar código:

1. explicar qué se va a cambiar,
2. indicar qué archivos se tocarían,
3. mencionar posibles riesgos.

Después de editar código:

1. resumir los archivos modificados,
2. explicar cómo probar los cambios,
3. indicar próximos pasos sugeridos.

## Estilo de desarrollo

- Priorizar claridad sobre optimización prematura.
- Usar nombres descriptivos.
- Mantener responsabilidades separadas.
- Evitar archivos demasiado largos.
- Agregar comentarios solo cuando ayuden a entender decisiones no obvias.
